# Recursive Self-Improvement Migration Note V0.1

The reusable recursive-improvement engine and fixture-based comparison harness are now part of
the sanitized Brain repository. Both remain shadow-only and cannot apply changes.

The private runtime also contains a domain-specific Shadow Day comparison tool. That tool depends
on private planning modules, Founder review inputs, and domain-specific fixtures. It is not the
same contract as the generic recursive-improvement harness and is intentionally not copied here.

The portable receipt-chain contract is included as `receipt_chain_v0_1.py`. It validates in-memory
hash-linked provenance only. It does not persist receipts, execute work, promote memory, or create
authority.

This note records a boundary decision, not an activation or independent-review result.
